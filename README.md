Top-down twin-stick arena survival in the hadal trench. Pilot a bathyscaphe, harpoon the things that live in the dark, level up through draft cards, and slay the Leviathan at depth 10 — or die trying.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move, mouse to aim, Space to dash. No network needed; the game is static files under `game/`.
